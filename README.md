# 原版：计划书与 PPT 工作台

这是一个本地功能 Demo。它把流程分为：设定大纲、人工审核、生成计划书草稿、选择 PPT 模板、生成副本，以及逐页修订和查询政策。

## 当前可以做什么

- 根据已确认的大纲和项目设定，按规则生成可编辑的计划书草稿。缺少的资料保留待补充标记；尚未接入大模型扩写。
- 将草稿摘要填入已标注模板的第 2 页，检查文字容量，并保留原来的文本位置、字号和图片框。
- 浏览模板的 22 页，逐页修改受支持的文本位置；查询全国官方政策资料并将选中的出处写入对应页的备注。
- 生成新的 PPTX 副本，记录模板保护检查与 WPS 人工复核状态。大纲或内容变化后，旧确认会失效。

目前只适配这一份平安货运模板。其他页保留原项目的内容，表格、图表和原图片没有自动替换；这还不是可把任意模板自动改成完整新主题的产品。联网政策查询结果有限，没有可靠结果时回退到已核验的资料库。

## 在原来的 Mac 上运行

此代码目前依赖原电脑上的 Codex 运行时、演示文稿工具包、原始模板和模板预览缓存。仓库不包含原始 PPT、用户草稿、已生成文件或这些工具包。代码中仍有本机绝对路径，不能保证在另一台电脑开箱即用。

1. 确认原始模板仍在代码指定位置，文件内容与代码中的 SHA-256 一致。
2. 在这个仓库的根目录执行以下命令，连接原项目的模板预览缓存：

   ```sh
   mkdir -p .work
   ln -s '/Users/wangdajin/我的文稿/agent task/codex 任务尝试/ppt-template-study/.work/source-render' .work/source-render
   ```

   如果 `.work/source-render` 已存在，无需重复创建。预览缓存来源于原模板，未上传到仓库。
3. 在 Finder 中双击 `product-demo/启动产品Demo.command`，或在终端运行：

   ```sh
   ./product-demo/启动产品Demo.command
   ```

   终端显示“工作台已就绪”后会打开 `http://127.0.0.1:5186/prototype/ppt-template`，请保持终端运行。仅在这台电脑本地监听。

源码使用 Codex 自带的 Node、Python、`jszip`、`sax`、`sharp` 和 `@oai/artifact-tool` 等依赖，并调用演示文稿工具包中的渲染和校验程序。换电脑需要修改 `product-demo/server.mjs`、`demo-prototype/run-demo.mjs` 和启动脚本中的路径，准备相应依赖、原模板及预览缓存，再自行验证。

这份源码副本的工作台启动脚本已调整为直接运行本仓库中的 `server.mjs`；其余工作台和演示文稿引擎源码来自本地 Demo。计划书和生成结果写在本仓库被忽略的 `.work/` 与 `output/` 中。

## 注意事项

文字容量为估算，最终效果需在 **WPS Office** 中检查。原模板有缺失字体提示；第 18 页原图表缓存问题和大文件下完整图表校验限制仍需处理。概念配图并非实测或部署证据。
