# 原版：计划书与 PPT 工作台 0.2.1

> 这是原始 Demo 的使用记录。GitHub 源码副本的运行方法和环境限制，请先看[仓库首页](../README.md)。

本地功能 Demo：**设定大纲 → 人工审核 → 计划书草稿 → 上传模板 → 自动生成 → 逐页审核修改**。

## 启动

在 Finder 中双击本目录的 `启动产品Demo.command`。终端显示“工作台已就绪”后会自动打开 [工作台](http://127.0.0.1:5186/prototype/ppt-template)，请保持这个终端运行。若 Codex 将脚本打开为文本，请在终端执行下面这一整行命令：

```sh
"/Users/wangdajin/我的文稿/agent task/codex 任务尝试/ppt-template-study/product-demo/启动产品Demo.command"
```

按 Control+C 或关闭服务终端可以停止服务。使用这台 Mac 的 Codex 内置 Node、Python 和演示文稿依赖，没有增加 npm 依赖；换电脑需要配置运行路径。

启动入口使用这台 Mac 上明确的服务路径，从用户目录运行也能找到服务。重复启动会识别已有工作台并打开它，不会停止其他服务。启动回归验证使用 `npm run test:launcher`，覆盖直接运行、按文本执行和 source 三种入口。

## 操作流程

1. **设定大纲**：填写题目、简称、服务对象、问题、方案和已有事实，调整章节及要点。当前模板简称为 1–4 个字。
2. **人工审核**：核对事实、章节和资料缺口，填写意见并确认本版本大纲。未审核不能生成计划书。
3. **计划书草稿**：整理为可编辑 Markdown；缺少的数据、预算和成果材料保留【待补充】。可编辑、保存和下载。当前依据已审核内容及段落规则整理，未接入大模型扩写。
4. **上传模板**：在草稿之后选择 PPTX，或使用已经提供的平安货运模板。其他模板尚需适配。
5. **自动生成**：从草稿分配第二页五栏摘要，显示容量和阻塞问题。可以修改摘要、黄色重点及 PNG 配图，生成真实 PPTX 副本。
6. **逐页审核**：切换 22 页，修改原文字位置与本页说明；查找全国官方政策，核对原文和条件后引用到本页备注。更新 PPT 生成新版本，再用 **wpsoffice** 核对修改页并分别记录确认。

修改大纲会撤销旧审核、草稿和模板确认。修改 PPT 或引用会使旧复核失效。当前版本全部修改页确认后，“下载已复核 PPT”才可用；候选文件可先查看。

## 政策材料

自动查询尝试公开联网检索，只保留可确认的全国官方站点。没有可靠官方结果或连接失败时明确显示已核验资料库匹配，不把它称为完整实时搜索。

初始资料覆盖数智供应链、物流降本、人工智能、中小企业数字化和物流数据互联，资料库核验日期为 2026-10-12。结果保留官方 URL、网页发布日期、取得时的发文日期及使用条件。规划期结束的材料标为历史背景。

只向搜索服务发送关键词，不发送完整计划书。选定资料写入本页原生备注，计划书下载稿附加政策参考。政策背景不能自动变成项目成果、补贴资格或资质。

## 支持边界

- 自动摘要适配第二页；其他页原内容保留，但可逐页修订。324 个文本对象支持在原位置、原段数和原文长度预算内替换。
- 位置、层级、母版、字体声明和图片框保持。一般文本修订沿用原段落首个文字格式，复杂富文本需要 WPS 复核。
- 表格、图表和其他页原图片没有自动更新，不能当作全套新题目已完成。第二页五张图片可用示例或上传 PNG。
- 字体有缺失提示，容量为近似估算，网页预览可能与 WPS 不同。
- 第 18 页原图表缓存问题保留，标准图表校验有 128 MiB 文件限制；未完成检查会显示。
- WPS 打开请求与人工确认分开记录。动画及跨设备一致性未验证。

## 文件与状态

仅监听 `127.0.0.1`。大纲、草稿、模板确认、逐页修订与引用保存在 `.work/workflow.json`；上传配图在 `.work/uploads/`；计划书和 PPT 版本在 `output/`；原模板只读。已完成任务和复核记录会保存并在重启后恢复，生成中的任务暂不支持断点恢复。

第二页备注改写为当前项目的草稿、事实与配图说明；其他页的原内容和备注仍须逐页核对。

`workflow.mjs` 管理大纲、审核和草稿；`policies.mjs` 管理政策资料及搜索；`model.mjs` 管理摘要；`server.mjs` 为本地接口；`public/` 为六步界面，复用 `demo-prototype/` 保护模板的引擎。

本地验证产品，没有发布到云端。实际验证结果见同目录 `NOTES.md`。
